# Эмулятор UNIX-подобной оболочки — вариант 16

Учебный проект по дисциплине «Конфигурационное управление».
В архиве находится **только Этап 1 — REPL** для варианта 16.

## Что реализовано

- CLI/REPL;
- prompt содержит имя VFS;
- раскрытие переменных окружения реальной ОС (`$HOME`, `${USER}` и т. п.);
- сообщения об неизвестных командах;
- сообщения о неправильном количестве аргументов;
- заглушки `ls` и `cd`, выводящие имя команды и её аргументы;
- команда `exit`;
- интерактивная обработка команд и ошибок;
- автоматические тесты Этапа 1.

## Запуск

Linux/macOS:

```text
chmod +x run.sh
./run.sh
```

Windows:

```text
run.bat
```

## Запуск тестов

Linux/macOS:

```text
./run.sh test
```

Windows:

```text
run.bat test
```

## Пример интерактивной работы

```text
vfs$ ls /home
ls: /home
vfs$ cd /home
cd: /home
vfs$ ls $HOME
ls: /Users/student
vfs$ unknown
unknown: command not found
vfs$ cd one two
cd: too many arguments
vfs$ exit
```

## Соответствие Этапу 1

**Пункт 1. CLI** — программа запускается из командной строки и работает в
интерактивном режиме REPL.

**Пункт 2. Prompt** — приглашение содержит имя VFS: `vfs$ `.

**Пункт 3. Парсер** — перед разбором строки раскрываются переменные окружения
реальной ОС, например `$HOME`.

**Пункт 4. Ошибки** — неизвестная команда и неправильное количество аргументов
сообщаются пользователю.

**Пункт 5. Заглушки `ls`, `cd`** — команды пока не работают с настоящей VFS,
а выводят своё имя и переданные аргументы.

**Пункт 6. `exit`** — завершает интерактивный режим.

**Пункт 7. Демонстрация** — интерактивные примеры приведены выше; автоматические
тесты находятся в `tests/test_shell.py`.
