# Эмулятор UNIX-подобной оболочки — вариант 16

Учебный проект по дисциплине «Конфигурационное управление».
Реализованы **этапы 1 и 2** практической работы для варианта 16.

## Этап 1 — REPL

- CLI/REPL;
- prompt содержит имя VFS;
- раскрытие переменных окружения реальной ОС (`$HOME`, `${USER}`);
- ошибки неизвестных команд и неправильного числа аргументов;
- заглушки `ls` и `cd`, выводящие имя команды и аргументы;
- команда `exit`.

## Этап 2 — Конфигурация

- `--vfs` — путь к физическому расположению VFS;
- `--script` — путь к стартовому скрипту;
- при запуске выводятся значения обоих параметров;
- стартовый скрипт поддерживает комментарии `#`;
- при выполнении скрипта на экране видны и ввод, и вывод;
- ошибки выполнения скрипта выводятся в stderr с номером строки;
- коды возврата: `0` — успех, `1` — были ошибки в скрипте,
  `2` — скрипт не найден или не читается;
- скрипты реальной ОС в `scripts/` проверяют все параметры запуска.

## Запуск

```text
chmod +x run.sh scripts/*.sh
./run.sh
./run.sh --vfs vfs/base64/minimal.json --script scripts/demo_stage2.txt
./run.sh test
```

Windows: `run.bat` с теми же аргументами.

## Скрипты проверки этапа 2

| Скрипт | Что проверяет |
| --- | --- |
| `scripts/stage2_vfs_only.sh` | только `--vfs` |
| `scripts/stage2_script_only.sh` | только `--script` |
| `scripts/stage2_both.sh` | оба параметра |
| `scripts/stage2_errors.sh` | ошибка в скрипте и отсутствующий скрипт |
