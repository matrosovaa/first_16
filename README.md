# Эмулятор UNIX-подобной оболочки — вариант 16

Учебный проект по дисциплине «Конфигурационное управление».
Реализованы **этапы 1, 2, 3 и 4** практической работы для варианта 16.

## Этап 1 — REPL

- CLI/REPL;
- prompt содержит имя VFS;
- раскрытие переменных окружения реальной ОС;
- ошибки неизвестных команд и неправильного числа аргументов;
- заглушки `ls` и `cd`;
- команда `exit`.

## Этап 2 — Конфигурация

- `--vfs` — путь к физическому расположению VFS;
- `--script` — путь к стартовому скрипту;
- вывод обоих параметров при запуске;
- комментарии `#` в стартовом скрипте;
- вывод команд скрипта и результатов;
- сообщение об ошибках выполнения скрипта;
- несколько скриптов реальной ОС для проверки параметров.

## Этап 3 — VFS

- источник VFS — JSON-файл;
- JSON загружается целиком в память;
- исходный файл не распаковывается и не изменяется;
- добавлены минимальная VFS, VFS с несколькими файлами и VFS с тремя
  уровнями вложенности;
- добавлен стартовый скрипт проверки подключенной VFS.

Настоящая логика `ls` и `cd` здесь не реализуется: для варианта 16 она
относится к этапу 4.

## Этап 4 — Основные команды

Приглашение теперь показывает имя VFS и текущий каталог: `project:/src$`.
Если `--vfs` не указан, эмулятор запускается с пустой VFS в памяти.

| Команда | Описание |
| --- | --- |
| `ls [-l] [путь]` | список каталога или файл; `-l` показывает права и размер |
| `cd [путь]` | смена каталога; без аргумента переход в корень VFS |
| `date [+формат]` | текущее время; формат как у `strftime`, например `+%Y-%m-%d` |
| `find [путь...] [-name шаблон] [-type f\|d]` | рекурсивный поиск по VFS |

Пути поддерживают `.`, `..`, абсолютную и относительную запись. Выше корня
подняться нельзя: `cd ..` в корне остается в корне.

Ошибки сообщаются в стиле UNIX: `ls: cannot access 'x': No such file or
directory`, `cd: x: Not a directory`, `find: unknown predicate`, а также
неверные опции и лишние аргументы.

Структура кода:

- `src/shell.py` — REPL, параметры запуска, стартовый скрипт;
- `src/commands.py` — логика `ls`, `cd`, `date`, `find`;
- `src/vfs.py` — загрузка JSON-VFS и операции над деревом в памяти;
- `src/errors.py` — исключения оболочки.

## Запуск

### Интерактивно

```text
chmod +x run.sh
./run.sh
```

### Этап 2

```text
./run.sh --vfs vfs/minimal.json --script scripts/demo_stage2.txt
```

### Этап 3

```text
./scripts/stage3_nested.sh
```

### Этап 4

```text
./scripts/stage4_demo.sh
```

Пример диалога:

```text
project:/$ cd src
project:/src$ ls -l
-rw-r--r--     14 main.py
drwxr-xr-x   4096 utils
project:/src$ find -name "*.py"
./main.py
./utils/helpers.py
project:/src$ date +%Y-%m-%d
2026-10-10
project:/src$ cd missing
cd: missing: No such file or directory
```

### Тесты

```text
./run.sh test
```
