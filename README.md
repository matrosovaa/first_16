# Эмулятор UNIX-подобной оболочки — вариант 16

Учебный проект по дисциплине «Конфигурационное управление».
Реализованы **этапы 1, 2 и 3** практической работы для варианта 16.

## Этап 1 — REPL

- CLI/REPL;
- prompt содержит имя VFS;
- раскрытие переменных окружения реальной ОС (`$HOME`, `${USER}`);
- ошибки неизвестных команд и неправильного числа аргументов;
- заглушки `ls` и `cd`, выводящие имя команды и аргументы;
- команда `exit`.

## Этап 2 — Конфигурация

- `--vfs` — путь к физическому расположению VFS;
- `--script` — путь к стартовому скрипту;
- при запуске выводятся значения обоих параметров;
- стартовый скрипт поддерживает комментарии `#`;
- при выполнении скрипта на экране видны и ввод, и вывод;
- ошибки выполнения скрипта выводятся в stderr с номером строки;
- коды возврата: `0` — успех, `1` — были ошибки в скрипте,
  `2` — скрипт не найден или не читается;
- скрипты реальной ОС в `scripts/` проверяют все параметры запуска.

## Этап 3 — VFS

- источник VFS — JSON-файл из папки `vfs/base64/`;
- каталог — JSON-объект, файл — строка с содержимым в **base64**
  (так хранятся и текст, и двоичные данные, например `logo.bin`);
- JSON целиком загружается в память и декодируется в дерево
  каталогов и файлов; исходный файл не распаковывается и не изменяется;
- имя VFS (имя JSON-файла) используется в приглашении к вводу;
- ошибки VFS (нет файла, неверный JSON, неверный base64) выводятся
  сообщением, без traceback, код возврата `2`;
- три варианта VFS: `minimal.json`, `files.json`, `nested.json`
  (четыре уровня вложенности), плюс `invalid.json` для проверки ошибок.

`ls` и `cd` остаются заглушками: их логика относится к этапу 4.

## Запуск

```text
chmod +x run.sh scripts/*.sh
./run.sh
./run.sh --vfs vfs/base64/files.json --script scripts/demo_stage3.txt
./run.sh test
```

Windows: `run.bat` с теми же аргументами.

## Скрипты проверки этапа 2

| Скрипт | Что проверяет |
| --- | --- |
| `scripts/stage2_vfs_only.sh` | только `--vfs` |
| `scripts/stage2_script_only.sh` | только `--script` |
| `scripts/stage2_both.sh` | оба параметра |
| `scripts/stage2_errors.sh` | ошибка в скрипте и отсутствующий скрипт |

## Скрипты проверки этапа 3

| Скрипт | Что проверяет |
| --- | --- |
| `scripts/stage3_minimal.sh` | минимальная VFS |
| `scripts/stage3_files.sh` | VFS с несколькими файлами и каталогами |
| `scripts/stage3_nested.sh` | VFS с вложенностью не менее 3 уровней |
| `scripts/stage3_errors.sh` | отсутствующая и неверная VFS |
| `scripts/stage3_all.sh` | стартовый скрипт `test_all.txt` со всеми командами и ошибками |
